# SHE-GUARD – Dataset Resources

This file contains the original dataset sources used in the development of SHE-GUARD.

## 1. Audio Distress Detection
- Dataset Name: Neural Information Processing group GENeral Sounds events database
- Source: https://zenodo.org/records/2535878?utm_source=chatgpt.com
- Purpose: Scream and distress audio classification.

## 2. Motion Analysis
- Dataset Name: PAMAP2 Physical Activity Monitoring Dataset
- Source: https://huggingface.co/datasets/rnicrosoft/PAMAP2/tree/main
- Dataset:https://drive.google.com/drive/folders/1FIQS4_i7IfXaL1fzNeMamSciGStxD0rG?usp=drive_link
- Purpose: Wearable sensor-based activity classification.

## 3. Geographical Risk Intelligence
- Dataset Name: Karnataka Crime Statistics (2023–2025)
- Source: https://data.opencity.in/dataset/?groups=bengaluru&organization=bengaluru-city-police&utm_source=chatgpt.com
- Purpose: Geographical crime statistics and risk estimation.
